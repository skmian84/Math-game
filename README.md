# Math Adventure Game (Python)

A kid-friendly Python game for ages around 6 that practices:

- Addition
- Subtraction
- Number pattern recognition
- Odd and even numbers
- Higher/lower comparison

All questions stay in the 0-100 range with **5 levels of difficulty**.

## Run

```bash
python3 math_game.py
```

## Levels

- Level 1: numbers up to 10
- Level 2: numbers up to 25
- Level 3: numbers up to 50
- Level 4: numbers up to 75
- Level 5: numbers up to 100

Each round has 10 questions and shows a score summary at the end.
